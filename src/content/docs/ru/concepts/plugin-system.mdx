Система плагинов — проектируемый механизм расширения Gateway интеграциями и операционными модулями.

:::note[Статус реализации]
В разработке. Ориентир — не раньше версии 2.20; версия и срок выпуска могут измениться.
:::

## Назначение

Плагин представляет отдельное расширение возможностей Gateway. Система плагинов должна определить, как такие расширения подключаются к приложению и взаимодействуют с его ядром.

Область применения — интеграции с внешними системами и дополнительные операции управления инфраструктурой. Конкретные точки расширения ещё не определены.

## Место в архитектуре

Механизм подключения плагинов относится к ядру Gateway. Он не выделяется в самостоятельную функцию тарифного плана.

Плагин и внешний API-клиент — разные способы интеграции. Внешний клиент обращается к уже доступным операциям Gateway через REST API или MCP. Плагин предназначен для расширения возможностей самого приложения. Существующие интеграции пока не образуют публичного контракта системы плагинов.

## Состояние реализации

Подключение и управление плагинами ещё не реализованы. Формат пакета, интерфейсы взаимодействия с ядром, модель разрешений и правила совместимости находятся на стадии проектирования. SDK и инструкции по разработке и установке появятся после определения этих контрактов.

Для интеграций с текущими версиями Gateway используются [REST API, OAuth и MCP](/ru/integrations/api-and-mcp/).
