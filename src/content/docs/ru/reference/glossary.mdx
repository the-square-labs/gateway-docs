# Глоссарий

**Additional Route** — Расположение с буквальным префиксом пути внутри управляемого Ingress Route.

**Binding** — Долговечная связь, предоставляющая одному управляемому ресурсу доступ к другому, например идентичность приложения для базы данных.

**Build Worker** — Выделенный профиль Docker daemon, использующий BuildKit/containerd без сокета Docker Engine.

**Deployment** — Стабильная идентичность приложения с сине-зелёными runtime-слотами и состоянием отката.

**Managed node** — Хост, выполняющий ограниченную роль daemon Gateway.

**Pages Deployment** — Неизменяемый релиз артефакта статического сайта.

**Relay** — Долговечная аутентифицированная служба плоскости данных и публичный владелец `9443/tcp`.

**Route** — Управляемое определение трафика nginx; сохраняемые API могут использовать историческое имя `proxy-host`.

**Secure Link** — Поддерживаемое приватное аутентифицированное соединение между управляемыми Gateway ресурсами, а не универсальный VPN.

**Tag** — Изменяемый указатель релиза Pages на неизменяемый Deployment.

**Task** — Долговечная операция, например сборка, миграция, Deployment или обновление.

**Access List** — Переиспользуемая политика Ingress с IP-правилами и необязательной HTTP basic authentication.

**Capability** — Возможность, о здоровом состоянии которой сообщает управляемый daemon; используется для допуска операций, безопасно поддерживаемых хостом.

**Database binding listener** — TCP listener, принадлежащий целевому Docker daemon в приватной bridge network конкретной привязки. Это не отдельный Container-коннектор для каждой привязки.

**Desired state** — Долговечная конфигурация, которую Gateway ожидает от владеющего daemon или сервиса.

**Folder** — Организационная граница и граница прав, группирующая поддерживаемые ресурсы Gateway.

**Inference token** — Отдельные учётные данные `gwi_` для плоскости данных Gateway Inference, отделённые от обычных API-учётных данных Gateway.

**Managed database** — Экземпляр PostgreSQL, Redis или ClickHouse, созданный и эксплуатируемый на Database Node.

**Operation ID** — Долговечный идентификатор для реконсиляции команды жизненного цикла, если её немедленный ответ потерян или прерван.

**Pages Project** — Ресурс статического сайта с неизменяемыми Deployments, изменяемыми Tags, конфигурацией источника и Routes.

**Reported state** — Последнее состояние инвентаря, capability или health, подтверждённое владеющим daemon.

**Route-owned binding** — Связь Secure Link, создаваемая и выводимая из эксплуатации вместе с владеющим Ingress Route.

**Runtime profile** — Ограниченный режим daemon или рабочей нагрузки с определённой capability и границей безопасности, например Build Worker, Databases, Default runtime или Secure Runtime.

**System PKI** — Скрытые центры сертификации и идентичности для управляемого транспорта Gateway, отделённые от пользовательской Internal PKI.
